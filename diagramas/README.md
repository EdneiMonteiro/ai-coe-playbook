# Diagramas

Espaço reservado para diagramas do playbook, como:

- modelo hub-and-spoke;
- modelo federado/híbrido;
- arquitetura de plataforma corporativa de IA;
- ciclo de vida de PoC a produto;
- evolução de maturidade do CoE de IA.

Preferir formatos editáveis e versionáveis quando possível, como Mermaid, PlantUML, SVG ou draw.io exportado com XML.
