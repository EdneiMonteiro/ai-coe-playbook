# Artefatos operacionais

Templates reutilizáveis para apoiar a criação e operação de um CoE de IA.

## Artefatos disponíveis

- [`raci-coe-ia.md`](raci-coe-ia.md) — responsabilidades de referência para CoE, plataforma, produto, dados, segurança/risco/compliance e sponsor executivo.
- [`charter-coe-ia.md`](charter-coe-ia.md) — modelo resumido de mandato, escopo, princípios e direitos de decisão.
- [`template-avaliacao-risco-ia.md`](template-avaliacao-risco-ia.md) — ficha operacional para triagem e aprovação de casos de uso de IA.

Os artefatos são pontos de partida. Adapte-os ao setor, jurisdição, maturidade, apetite de risco e modelo operacional da organização.
