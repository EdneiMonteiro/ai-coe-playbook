# Contributing

Contribuições são bem-vindas. Este projeto credita formalmente quem contribui: release notes, `CONTRIBUTORS.md`, `CITATION.cff` quando configurar coautoria substantiva, e DOI Zenodo próprio de cada versão. Os critérios estão em [CONTRIBUTORS.md](CONTRIBUTORS.md).

## Como contribuir

**[Abra uma Discussion](https://github.com/EdneiMonteiro/ai-coe-playbook/discussions)** — este é o canal de entrada para qualquer proposta:

- correção de fato (erro, link quebrado, citação incorreta, norma revogada);
- sugestão editorial (clareza, escopo, redação);
- proposta de nova seção, exemplo, artefato ou diagrama;
- revisão crítica de uma ou mais seções.

Contribuições aceitas são incorporadas pelo mantenedor e creditadas nominalmente a partir da v1.1.

## Issues e Pull Requests

Para reduzir spam e manter o projeto sustentável, **a criação de issues e pull requests é restrita a colaboradores com acesso `write`**. Se você quiser acesso para contribuir diretamente, peça pela Discussion.

O branch padrão também é protegido: exclusão e force-push estão desabilitados.
